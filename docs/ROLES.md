# Роли

- STUDENT — просмотр своих данных.
- TEACHER — оценки, комментарии и домашние задания только в назначенных группах/предметах.
- CURATOR — работа с группой и объявлениями без изменения оценок преподавателей.
- ADMIN — управление пользователями, группами, назначениями и аудитом.

Все права должны проверяться на сервере, а не только интерфейсом.
