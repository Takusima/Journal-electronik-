# Электронный журнал КМК

Приложение для преподавателей: группы, оценки, комментарии, домашние задания и уведомления.

## Архитектура

- `apps/desktop` — Windows-приложение на Electron
- `server` — общий API-сервер
- `packages/shared` — общие типы
- `database` — PostgreSQL schema/migrations
- `docs` — документация

Преподавателю не требуется устанавливать Node.js, PostgreSQL или другие зависимости: распространяется готовый Windows-инсталлятор.
